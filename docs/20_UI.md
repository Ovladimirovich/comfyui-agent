# 20 — UI (M9)

> Source of truth: `PROJECT_SPEC.md` §22 (APPROVED). Derivative document — не вводит новых архитектурных решений.

## Назначение
Минимальный веб-интерфейс поверх `ConversationAgent`/`AssetStore`: чат (естественный язык →
capability через planner) + превью `active_asset` + прогресс исполнения через SSE. Делает
многоходовой контекст M7 видимым пользователю.

## Реализация
- `app/ui.py` — `ComfyUIServer` (тонкий слой над `ConversationAgent`) + `SessionStream`
  (replay-safe буфер SSE на session) + `_make_handler` (stdlib `http.server`,
  `ThreadingHTTPServer`). Без новых зависимостей (flask/fastapi намеренно не используются).
- `POST /turn` запускает `ConversationAgent.turn(session_id, request=..., capability=..., ...)`
  в фоновом потоке и сразу возвращает 200. События исполнения пушатся в `SessionStream`.
- `GET /events?session_id=...` — SSE: `start` → `status(RUNNING)` → `result` | `error`.
  `result` несёт `active_asset`, `active_workflow`, `active_job`, `assets`, `preview` (URL `/asset/<id>`).
- `GET /asset/<id>` — байты ассета (content-type по `mime`/`asset.path`); `<img>`/`<video>`/`<audio>`
  по типу в превью.
- `GET /api/session?session_id=...` — JSON контекста session (`ConversationContext.as_dict()`).
- `GET /` — HTML (чат + превью + JS `EventSource`). session_id хранится в `localStorage`.
- Запуск: `python -m app.ui` (env `AGENT_UI_HOST`, `AGENT_UI_PORT`=8189, `AGENT_ASSET_DIR`,
  `COMFY_REMOTE_URL`/`COMFY_LOCAL_URL` для provider через `BackendCatalog.from_env()`).

## Progress (честный)
SSE отражает реальные переходы состояния `Job` (queued→running→success/failed). Гранулярный
процент исполнения (1–100%) требует хука в `WorkflowEngine` (WS-трекинг прогресса) — вне M9.
Ошибка исполнения стримится как `error` (`AgentError`/`RuntimeError`), не маскируется.

## Session isolation
Тот же `ConversationAgent.sessions[session_id]`, что и в M7. Разные session не смешивают
`active_asset`/`assets`/`jobs` (доказано `test_ui_m9.py::test_ui_session_isolation`).

## Media-agnostic invariant (AD-03)
UI не ветвится по media: превью выбирает тег по `asset.type` (`image`/`video`/`audio`) на клиенте;
сервер лишь отдаёт байты по id. Execution core не тронут.

## Тесты
`tests/test_ui_m9.py` (5): индекс отдаётся; `turn` → `active_asset` + preview (PNG magic); SSE
содержит `start`/`status`/`result` (state SUCCESS); session isolation (A≠B); `GET /asset/<bad>` → 404.
Оффлайн через `FakeProvider` (как `test_agent.py`), без mock-success.

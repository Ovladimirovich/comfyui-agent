# REVIEW_PROTOCOL.md

Перед завершением задачи ИИ обязан проверить:

<!-- id:2m5r7x -->
```text
□ соответствует PROJECT_SPEC
□ не нарушает invariants
□ не создаёт hidden coupling
□ не дублирует существующий механизм
□ обработаны ошибки
□ тесты добавлены/обновлены
□ нет случайных изменений
□ документация актуальна
□ нет незадокументированных решений
```

Все пункты должны быть выполнены. При невыполнении — вернись к IMPLEMENT / PLAN.
Незадокументированное архитектурное решение = нарушение (вынеси в DECISION_LOG + CHANGE_PROTOCOL).

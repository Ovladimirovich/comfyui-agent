# HARDWARE_PROFILE.md — Оптимизация для AMD Radeon RX 570 4GB

## Конфигурация

| Компонент | Значение |
|-----------|----------|
| GPU | AMD Radeon RX 570 (Polaris, GCN 4) |
| VRAM | 4 GB GDDR5 |
| DirectML | torch-directml (PyTorch 2.4.1+cpu) |
| CPU | Intel Xeon E5-2650 v2 (8C/16T, Ivy Bridge) |
| RAM | 32 GB DDR3 1600 MHz |
| OS | Windows 10 |
| ComfyUI | v0.3.70 |

## VRAM лимиты (эмпирические замеры)

| Разрешение | Steps | Статус | Время | VRAM tensor |
|------------|-------|--------|-------|-------------|
| 256×256 | 3 | ✅ OK | 8.0s | ~40 MB |
| 384×384 | 3 | ✅ OK | 6.0s | ~90 MB |
| 384×384 | 20 | ✅ OK | 20.0s | ~90 MB |
| 512×512 | 3 | ✅ OK | 8.3s | ~160 MB |
| 512×512 | 20 | ✅ OK | 28.0s | ~160 MB |
| 640×640 | 3 | ✅ OK | 10.0s | ~256 MB |
| 768×768 | 3 | ❌ OOM | 14.0s | 604 MB (fail) |
| 896×896 | 3 | ❌ OOM | 20.0s | 822 MB (fail) |
| 1024×1024 | 3 | ❌ OOM | 26.0s | 1074 MB (fail) |

**Максимальное безопасное разрешение:** 640×640

## Запуск

### Рекомендуемые флаги

```bash
python main.py --directml --lowvram --cache-ram 8 --listen 127.0.0.1 --port 8188
```

- `--directml` — GPU ускорение через DirectML (обязательно для AMD)
- `--lowvram` — выгружает модель в RAM между операциями (критично для 4GB VRAM)
- `--cache-ram 8` — резервирует 8GB RAM для кэша моделей (у нас 32GB RAM)

### Скрипт запуска

```bash
# Из корня ComfyUI
start.bat
# Или вручную:
venv\Scripts\python.exe main.py --directml --lowvram --cache-ram 8 --listen 127.0.0.1 --port 8188
```

## Автоматический подбор разрешения

Agent автоматически определяет VRAM через `wmic` и выбирает безопасное разрешение:

| VRAM | Разрешение по умолчанию |
|------|------------------------|
| < 3 GB | 256×256 |
| 3–3.8 GB | 384×384 |
| 3.8–6 GB | 512×512 |
| > 6 GB | 640×640 |

Пользователь всегда может переопределить размер в тексте: "Create a cat 256x256"

## Ограничения

1. **--lowvram замедляет первый прогон** (~25s для 384×384 10 steps) — модель загружается из RAM в VRAM
2. **Кэширование помогает** — повторные генерации < 1s (модель уже в VRAM)
3. **> 640×640 OOM** — tensor allocation > 600 MB не влезает в 4GB VRAM
4. **DirectML reports 1GB** — PyTorch/DirectML показывает только выделенную VRAM, не физическую
5. **Xeon E5-2650 v2 без AVX2** — CPU-режим очень медленный, всегда используйте GPU

## Производительность

| Сценарий | Время |
|----------|-------|
| Первый прогон 384×384 10 steps | ~25s |
| Повторный прогон 384×384 10 steps | < 1s |
| Первый прогон 512×512 10 steps | ~30s |
| Повторный прогон 512×512 10 steps | < 1s |
| 3-turn тест (384+512+256) | ~27s total |

## Рекомендации

1. **Всегда запускайте с `--lowvram`** — без него 512×512 OOM
2. **Используйте 10 steps для тестирования** — 20 steps удваивает время
3. **Кэшируйте модель** — первый прогон медленный, повторные быстрые
4. **Для продакшена** —考虑 upgrade GPU (RX 6600 8GB или RTX 3060 12GB)
